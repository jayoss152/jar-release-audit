# Security

This early project has no dedicated security-response SLA. Please do not put
secrets, proprietary archives or exploit material involving third-party systems in
public issues. Use GitHub's private vulnerability reporting if enabled on the
repository. If it is unavailable, open a minimal issue asking for a private contact
without disclosing sensitive details. Rotate any exposed real credential through
its issuer; deleting a file or obfuscating it does not revoke access.

Only the latest source version is currently maintained. See
[the threat model](docs/THREAT_MODEL.md) for supported checks and limitations.
